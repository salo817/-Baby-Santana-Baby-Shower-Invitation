# Baby Santana Baby Shower Invitation 👶🎉

Welcome to the Baby Santana Baby Shower Invitation website!

This is a simple, elegant web page to share the baby shower invitation digitally.

## 🚀 Live Site

Visit the live invitation: [https://salo817.github.io/-Baby-Santana-Baby-Shower-Invitation/](https://salo817.github.io/-Baby-Santana-Baby-Shower-Invitation/)

## 📋 What's Included

- `index.html` - Main invitation page
- `style.css` - Beautiful styling and animations
- `invitation.png` - Your invitation image (needs to be added)

## 📝 Setup Instructions

1. Convert your PDF to an image (PNG/JPG) using a tool like [Smallpdf](https://smallpdf.com/pdf-to-image)
2. Save the image as `invitation.png` in this repository
3. Update the email address in `index.html` if you want to customize the RSVP link

## ✨ Features

- Responsive design (works on mobile, tablet, desktop)
- Smooth animations and hover effects
- RSVP button with email functionality
- Beautiful gradient background

Enjoy celebrating! 🎊
